AWS Deployment Quickstart

Follow these standard blueprints to deploy this Flask application to your choice of AWS hosting service.

Deploy via Elastic Beanstalk CLI

AWS Elastic Beanstalk reads requirements.txt, builds packages, and uses Gunicorn automatically with application.py.

# Initialize EB application (select Python platform)
eb init -p python-3.11 my-flask-app

# Create environment (spins up Load Balancer & EC2 instances)
eb create flask-env

# Deploy code updates
eb deploy

# Open application in browser
eb open

Deploy via AWS App Runner

AWS App Runner automatically builds your container image from Git or Amazon ECR and handles TLS certificates, scaling, and load balancing.

# Build your local docker image
docker build -t flask-aws-app .

# Tag and push your image to Amazon ECR (Elastic Container Registry)
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin <aws_account_id>.dkr.ecr.us-east-1.amazonaws.com
docker tag flask-aws-app:latest <aws_account_id>.dkr.ecr.us-east-1.amazonaws.com/flask-aws-app:latest
docker push <aws_account_id>.dkr.ecr.us-east-1.amazonaws.com/flask-aws-app:latest

# In AWS App Runner Console:
# Create service -> Select ECR Repository -> Port 8080 -> Start Service.

Deploy to AWS ECS Fargate

Use ECS Fargate to run your container serverless. This gives you complete network, security, and scaling configuration control.

# Create cluster
aws ecs create-cluster --cluster-name flask-production

# Register ECS Task Definition (configures CPU, memory, Docker image)
aws ecs register-task-definition --cli-input-json file://ecs-task-def.json

# Create Fargate Service with Load Balancer mapping
aws ecs create-service --cluster flask-production --service-name flask-web-service --task-definition flask-aws-app --desired-count 2 --launch-type FARGATE --network-configuration "awsvpcConfiguration={subnets=[subnet-12345678],securityGroups=[sg-12345678],assignPublicIp=ENABLED}"
